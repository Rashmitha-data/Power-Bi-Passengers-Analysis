Power BI Passengers Analysis
Project Overview
This project analyzes passenger data using Microsoft Power BI.
Tools Used
- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization
Dashboard Features
- Total Passengers
- Male Passengers
- Female Passengers
- Average Passenger Age
- Delayed Passengers
- Cancelled Passengers
- Passenger analysis by country
- Interactive slicers
Files Included
- Airline Dataset.csv
- POWER BI PROJECT.pbix
- Dashboard Screenshot
Project Objective
The objective of this project is to analyze passenger data and create an interactive Power BI dashboard to identify useful patterns and insights.
